# AELUSA International Way — React + Tailwind CSS

Premium responsive corporate travel & hospitality website starter.

## Pages
- Home
- About AELUSA
- Services
- Corporate Solutions
- Global Network
- Contact / Request Assistance

## Navigation
Home | About | Services | Corporate Solutions | Global Network | Contact
Primary CTA: Request Assistance

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the local URL shown by Vite.

## Build
npm run build

## Notes
The demo uses Unsplash image URLs so the project stays lightweight. Replace them with licensed AELUSA photography before production. Update the placeholder phone/email/office details with the company's actual information.
